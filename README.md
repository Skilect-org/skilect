# 📖 About

Skilect is an AI-powered placement preparation platform that helps students prepare efficiently through personalized assessments, structured learning roadmaps, resume analysis, AI-powered mock interviews, and progress tracking.

Instead of guessing what to learn next, students receive a clear, personalized roadmap that guides them toward placement readiness.

---

# 🎯 Problem Statement

Students often struggle because they:

- ❌ Don't know what skills they are missing
- ❌ Have no structured preparation plan
- ❌ Lack quality interview practice
- ❌ Have resumes that aren't ATS-friendly
- ❌ Can't measure their placement readiness
- ❌ Lose consistency while preparing

---

# 💡 Solution

Skilect solves these challenges through AI by providing:

- 🧠 AI Skill Assessment
- 🛣️ Personalized Learning Roadmaps
- ✅ Smart Task Management
- 📄 Resume Analysis
- 📑 ATS Resume Checker
- 💬 AI Mock Interviews
- 📊 Progress Analytics
- 🎯 Placement Readiness Dashboard

---

# ✨ Core Features

| Feature | Description |

| 🧠 AI Skill Assessment | Analyze current skills and identify knowledge gaps |

| 📄 Resume Analyzer | AI-powered resume review and suggestions |

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Skilect-org/skilect.git
```

```bash
cd skilect
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
